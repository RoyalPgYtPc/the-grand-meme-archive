

WHAT YOU CAN SUBMIT
Images
- JPG / JPEG
- PNG
- WEBP
- GIF
- Screenshots of old memes
- Meme templates
- Reaction images
- Original memes
- Historical/old subreddit memes
Video
- MP4
- WebM
- Short meme videos
- Video memes originally posted to the subreddit
Other useful material
- Links to old Reddit posts
- Post IDs
- Original usernames
- Old versions of memes
- Higher-quality versions of already archived memes
- Information about the origin/context of a meme

WHAT WE DON’T WANT
Please do not submit:
- Malware or suspicious files
- Executable files (.exe, .bat, .sh, etc.)
- Archives containing unknown files
- Password-protected files
- Personal/private documents
- Doxxing or private personal information
- Copyright-infringing material submitted specifically to exploit the archive as a file host
- Extremely large files that aren’t necessary for preserving the meme
- Duplicate copies of memes already in the archive
- Unrelated files
-Spam

FILE SIZE
Please submit the smallest high-quality version that properly preserves the meme.
For example, don’t upload a 500 MB video when a 20 MB copy contains exactly the same content.
Large submissions may be rejected or compressed if they’re unnecessarily consuming archive storage.

DUPLICATES
Don’t worry if you accidentally submit something that’s already been submitted.
The archive will attempt to identify duplicates, and duplicate submissions won’t need to occupy additional permanent storage.

WHAT HAPPENS TO SUBMISSIONS?
Accepted submissions will be processed and entered into the archive with metadata such as:
Archive ID
Original Post
Author
Date
Score
Flair
Tags
Media Type
File Size
Archive Status

The eventual Search system will use this metadata to make archived memes searchable and filterable.

IMPORTANT
Submitting something does NOT guarantee permanent inclusion.
The archive team will decide what gets retained based on relevance, quality, historical value, duplication and available storage.
The server currently has 50 GB, so every megabyte matters.
If you’ve got an old r/MemeExchangeCommunism classic sitting on your computer, phone, hard drive or forgotten Reddit bookmarks:

SEND IT IN.
HOW TO SUBMIT
Submitting is simple:

1. Find a meme you want archived.
It can be an old post, a classic, your own meme, or something you think deserves preservation.

2. Download the best-quality copy you have.
Don’t worry if it’s not the original file, screenshots and compressed copies are still accepted.

3. Comment below with the meme attached.

4. Add the following information if you have it:
Original Post: Reddit link
Author: u/username
Date: DD/MM/YYYY
Title: Original post title
Notes: Anything useful about the meme

Example:
Original Post: reddit.com/r/MemeExchangeCommunism/comments/xxxxx
Author: u/example
Date: 14/08/2025
Title: My new Cat
Notes: One of the popular memes from the 2025 era of the subreddit.

DON’T HAVE ALL THE INFORMATION?
That’s fine.
Just submit the meme. The archive team can add or recover missing metadata later.

IMPORTANT
Please attach the actual media file to your comment whenever possible rather than only posting a link.
For Reddit posts that are still accessible, include the original post link so we can preserve its metadata alongside the media.
